# Claude plugins

This repository is a Claude Code plugin marketplace by Stefano Baghino. It holds only the catalog; each plugin lives in its own repository.

## Plugins

- [simple-claude-output-style](https://github.com/stefanobaghino/simple-output-styles) — An output style with clear and simple writing rules, adapted from ASD-STE100 Issue 9 for chat and code work.

## How to install a plugin

1. Add the marketplace: `/plugin marketplace add stefanobaghino/claude-plugins`
2. Install a plugin: `/plugin install simple-claude-output-style`
