# Claude plugins

This repository is a Claude Code plugin marketplace. It holds only the catalog; each plugin lives in its own repository.

## Plugins

- [simple-output-styles](https://github.com/stefanobaghino/simple-output-styles) — Output styles that make Claude write clearly, for everyone.

## How to install a plugin

1. Add the marketplace: `/plugin marketplace add stefanobaghino/claude-plugins`
2. Install a plugin: `/plugin install simple-output-styles`
