# Claude plugins

This repository is a Claude Code plugin marketplace by Stefano Baghino. It holds only the catalog; each plugin lives in its own repository.

## Plugins

- [simple-output-styles](https://github.com/stefanobaghino/simple-output-styles) — Output styles with clear and simple writing rules, adapted from ASD-STE100 Issue 9 and the Federal Plain Language Guidelines for chat and code work.

## How to install a plugin

1. Add the marketplace: `/plugin marketplace add stefanobaghino/claude-plugins`
2. Install a plugin: `/plugin install simple-output-styles`
